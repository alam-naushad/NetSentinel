# CICIDS2017 Feature Data Dictionary

This document provides a comprehensive inventory and data dictionary for all **79 raw columns** present in the official CICIDS2017 `MachineLearningCVE` CSV dataset (generated by CICFlowMeter).

## Schema Layer Architecture

```text
┌─────────────────────────────────────────────────────────────────────────┐
│ Layer 1: Raw CICIDS2017 Dataset Schema (78 numeric features + 1 Label)   │
│ - Direct output from CICFlowMeter (ISCX network capture processing)      │
│ - Column index 0 to 78                                                  │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │ Normalization Adapter
                                     ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ Layer 2: Canonical Model Feature Schema (data/metadata/feature_schema.json)│
│ - Verified numeric flow baseline features                                │
│ - Target Contract: raw_label (verbatim), attack_family, is_attack       │
│ - Leakage-safe, reproducible across models                               │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │ Contextual Integration
                                     ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ Layer 3: Live Telemetry Adapter Schema (Future Zeek / Suricata pipeline) │
│ - Zeek conn.log fields (e.g. proto, service, conn_state, duration)      │
│ - Live context fed into the Decision & Risk Engine                      │
└─────────────────────────────────────────────────────────────────────────┘
```

## Canonical Output Fields from Data Pipeline

When processed through `ml/data_pipeline.py`, the canonical output preserves:

1. **Features:**
   - `flow_duration_ms`: Flow Duration
   - `total_forward_packets`: Total Fwd Packets
   - `total_backward_packets`: Total Backward Packets
   - `total_forward_bytes`: Total Length of Fwd Packets
   - `total_backward_bytes`: Total Length of Bwd Packets
   - `packets_per_second`: Flow Packets/s
   - `destination_port`: Destination Port
2. **Targets:**
   - `raw_label`: Verbatim original string from the dataset (`BENIGN`, `DoS Hulk`, `FTP-Patator`, etc.)
   - `attack_family`: Normalized canonical family (`BENIGN`, `DOS`, `DDOS`, `PORT_SCAN`, `BRUTE_FORCE`, `BOTNET`, `WEB_ATTACK`, `INFILTRATION`, `HEARTBLEED`)
   - `is_attack`: Binary label (`0` for benign, `1` for attack)
